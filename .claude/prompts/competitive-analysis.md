# Competitive Analysis

Analyze competitors of [COMPANY] across key dimensions:

1. **Identify**: Search for direct and indirect competitors using web-search.
2. **Research**: Visit each competitor's website with playwright. Extract product info, pricing, team, funding.
3. **Compare**: Build feature comparison matrix in Excel across dimensions: product, pricing, target market, tech stack, market share.
4. **SWOT**: Create SWOT analysis for each competitor using sequentialthinking.
5. **Positioning**: Map competitors on 2x2 positioning grid (e.g., price vs features).
6. **Charts**: Generate comparison charts with chart-mcp.
7. **Report**: Create PowerPoint with executive summary, competitor profiles, comparison matrix, strategic recommendations.
8. **Save**: Save to `reports/competitive/[company]-YYYY-MM-DD/`.

**Parameters**: [company name] [industry] [dimensions to compare]
