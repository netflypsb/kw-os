# Trend Brief

Monitor and summarize current trends in [SECTOR/REGION]:

1. **Scan**: Search for recent news and analysis using web-search (last 7-30 days).
2. **Deep Read**: Fetch full articles with read-website-fast. For paywalled sites, use playwright.
3. **Data Points**: Extract quantitative data (market numbers, growth rates, indices) from financial portals.
4. **Signals**: Identify emerging trends, inflection points, and weak signals using sequentialthinking.
5. **Categorize**: Group findings into themes (economic, political, technological, social).
6. **Confidence**: Rate each finding (high/medium/low confidence) based on source quality and corroboration.
7. **Visualize**: Create trend charts and signal heatmap with chart-mcp.
8. **Brief**: Write 2-3 page intelligence brief in Word with executive summary, key findings, and outlook.
9. **Store**: Save key findings in memory for longitudinal tracking.
10. **Save**: Save to `reports/trends/[sector]-YYYY-MM-DD/`.

**Parameters**: [sector or region] [timeframe] [specific focus]
